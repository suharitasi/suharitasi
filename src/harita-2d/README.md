# harita-2d — MapLibre arşivi

Harita v3'ün (2D MapLibre atlas görünümü) kodu. v4'te /harita/ Three.js'e
geçti; bu kod havza veri haritası olarak ileride yeniden kullanılabilir.
Giriş dosyası: maplibre-main.js (import yolları harita/ dizinine göreydi,
yeniden kullanırken ../src/... yollarını güncelle).
